Архитектура знаний

Life OS превращает хаос информации в упорядоченную базу. Каждый материал проходит через конвейер и обретает форму.

Вход — URL, PDF, текст или YouTube. Система извлекает контент, классифицирует по области (промпт-инжиниринг, вайб-кодинг, долголетие, бессмертие) и создаёт заметку со строгим форматом.

Выход — структурированный Markdown в Obsidian, запись в SQLite, связи через локальный RAG-индекс. Ошибки не прерывают процесс — всё логируется.

Три столпа системы

Каждый модуль — грань кристалла. Вместе они образуют целостную архитектуру управления знаниями.

Obsidian

Хранилище знаний в Markdown. Строгий формат заметок: frontmatter, саммари, ключевые идеи, научный блок. Граф связей между идеями.

vault.md

RAG

Локальный индекс TF-IDF с чанкингом и косинусным поиском. Автоматические связи related между заметками. Дедупликация по SHA-256.

rag.index()

Python-агенты

Конвейер на Python 3.12: извлечение, классификация через Claude API, авто-раскладка по областям, YouTube-транскрипты, arXiv и bioRxiv.

Принципы ордена

Жёсткие правила, которые делают систему надёжной и предсказуемой — как кодекс древнего братства знаний.

  • 01 Никогда не перезаписывать существующие заметки — только создавать новые
  • 02 Ошибки логируются, но не прерывают конвейер — устойчивость превыше всего
  • 03 Теги только из существующих в хранилище — новые предлагаются, не создаются
  • 04 Низкая уверенность → other + #needs-review, заметка остаётся в Inbox
  • 05 API-ключи только из .env — секреты вне кода и конфигов
  • 06 Windows-совместимость: pathlib, utf-8, кроссплатформенные команды
